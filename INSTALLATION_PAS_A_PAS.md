# Installation V6.2.0 PROD

1. Faire une sauvegarde complète de MyBusiness.
2. Remplacer les fichiers de production sur GitHub.
3. Recharger avec Ctrl + F5.
4. Vérifier que le tableau de bord affiche V6.2.0 PROD.
5. Déployer le Worker calendrier en suivant `CALENDRIER_APPLE_INSTALLATION.md`.
6. Dans MyBusiness, ouvrir Calendrier puis cliquer sur « Vérifier le service », puis sur « Activer l’abonnement ».

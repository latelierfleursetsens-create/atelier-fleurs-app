# MyBusiness — V5.0.4 TEST

## Référentiel détaillé des créations mariage

Cette version utilise une seule liste de référence dans :

- le portail mariage destiné aux futures mariées ;
- l’assistant **Préparer mon rendez-vous** pour créer manuellement une fiche mariage ;
- la fiche mariage créée ;
- les lignes préparées pour le devis.

Seules les créations cochées sont ajoutées à la fiche et au devis. Un champ **Autre création ou demande** permet de saisir un besoin libre.

### Points à tester

1. Ouvrir `portail-mariage.html` et sélectionner plusieurs créations, ainsi qu’une demande libre.
2. Importer la demande dans **Clients → Demandes mariage**.
3. Transformer la demande en fiche mariage et vérifier que seuls les choix cochés apparaissent.
4. Créer manuellement une fiche avec **Préparer mon rendez-vous** et vérifier que la même liste est proposée.
5. Créer le devis et vérifier que les lignes correspondent exactement aux choix retenus.

Effectuer une sauvegarde avant installation.

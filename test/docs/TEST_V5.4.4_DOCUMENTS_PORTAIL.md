# Test V5.4.4 — Documents portail

## Devis
1. Lier le devis à une fiche mariage issue du portail.
2. Envoyer le devis par e-mail.
3. Vérifier le message confirmant sa publication dans l’espace client.
4. Vérifier les boutons Consulter, Télécharger et Valider en ligne.
5. Valider le devis et contrôler le statut dans MyBusiness.

## Facture
1. Créer une facture liée au même devis.
2. Envoyer la facture par e-mail.
3. Vérifier sa présence et son PDF dans l’espace client.

## Important
Les documents déjà envoyés avant cette version doivent être renvoyés une fois pour téléverser leur PDF dans Firebase Storage.

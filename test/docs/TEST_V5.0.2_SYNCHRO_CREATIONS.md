# Test V5.0.2 — Synchronisation des créations portail

1. Envoyer une demande depuis le portail en sélectionnant seulement Bouquet de mariée, Peigne ou accessoire fleuri et Autre demande.
2. Transformer la demande en fiche mariage.
3. Ouvrir l’onglet Créations.
4. Vérifier que la liste contient uniquement ces trois choix.
5. Vérifier que la zone Prestations complémentaires est vide.
6. Créer un devis et vérifier qu’il contient uniquement ces trois créations.
7. Ajouter ensuite des frais de déplacement : ils doivent apparaître comme prestation complémentaire sans modifier la liste des créations.
8. Ouvrir une ancienne fiche créée depuis le portail : elle doit être réparée automatiquement.

3. Vérifier que la somme des places correspond au total prévu.
4. Enregistrer : le stock est réservé selon la répartition de chaque activité.
5. Saisir une vente Squarespace, choisir l’événement puis l’activité.
6. Vérifier le tarif automatique, le nombre de places restantes et le paiement total/acompte.
7. Vérifier dans la liste le remplissage de chaque activité.
8. Vérifier dans Finances que le CA prévu est la somme places × tarifs, sans double comptage des encaissements.

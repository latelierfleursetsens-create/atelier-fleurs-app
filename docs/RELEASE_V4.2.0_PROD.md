# Version V4.2.0 PROD

Version de production validée à partir de la V4.2.0 TEST.

Fonctionnalités principales :
- ateliers multi-activités à une même date et dans un même lieu ;
- capacité, tarif et stock distincts pour chaque activité ;
- commandes Squarespace multi-places ;
- gestion des acomptes et paiements complets ;
- correction de l’atelier associé depuis l’historique ;
- participantes visibles dans la fiche atelier ;
- badges de paiement et d’atelier complet ;
- absence de double comptage du chiffre d’affaires.

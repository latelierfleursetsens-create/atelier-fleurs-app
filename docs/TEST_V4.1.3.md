# Protocole de test — V4.1.3 TEST

## Participante visible après correction

1. Créer ou utiliser un atelier privé ou en structure.
2. Modifier une vente Squarespace existante et la rattacher à cet atelier.
3. Ouvrir la fiche de l’atelier.
4. Vérifier que la section **Réservations site / participantes** affiche la cliente.
5. Vérifier le nombre de places et le montant encaissé.

## Réparation d’une liaison ancienne

1. Conserver une vente liée à un atelier mais supprimer temporairement son entrée participante dans les données de test.
2. Recharger MyBusiness.
3. Vérifier que la participante est recréée automatiquement dans le bon atelier.

## Changement d’atelier

1. Déplacer une vente de l’atelier A vers l’atelier B.
2. Vérifier que la cliente disparaît de A et apparaît dans B.
3. Vérifier que les places réservées sont recalculées dans les deux ateliers.

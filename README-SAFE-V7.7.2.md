# MyBusiness V7.7.2 SAFE — Réparation intelligente des liens mariage

- Conserve le stockage Firebase compressé V7.7.0.
- Conserve la détection des transformations incomplètes V7.7.1.
- Recherche une fiche existante par :
  - identifiant technique ;
  - sourceDemandeId ;
  - email ;
  - téléphone ;
  - nom/prénom + date du mariage.
- Répare automatiquement uniquement une correspondance unique et suffisamment forte.
- En cas de correspondance ambiguë, aucune réparation automatique.
- Aucune fiche, demande, devis, facture ou inspiration n'est supprimé.
- La réparation du lien ne modifie aucun contenu de la fiche mariage.
- Si un lien est réparé, MyBusiness demande un enregistrement explicite pour le rendre persistant.
